# Mobile Price Prediction Using Machine Learning

## Project Overview
This project predicts the price of smartphones based on their technical specifications using machine learning regression algorithms.

The system analyses smartphone features such as brand, battery capacity, screen size, RAM, camera specifications, processor and other hardware features to estimate mobile phone prices.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Gradio
- Jupyter Notebook

## Machine Learning Algorithms
1. Multiple Linear Regression
2. Ridge Regression
3. Lasso Regression
4. Decision Tree Regression
5. Random Forest Regression
6. Bagging Regression

## Project Workflow
1. Dataset loading
2. Data preprocessing and cleaning
3. Exploratory Data Analysis (EDA)
4. Feature selection
5. Categorical encoding
6. Numerical feature scaling
7. Model training and evaluation
8. Model comparison
9. Cross-validation
10. Hyperparameter tuning
11. Mobile price prediction using Gradio

## Evaluation Metrics
- Mean Absolute Error (MAE)
- Mean Squared Error (MSE)
- Root Mean Squared Error (RMSE)
- R² Score

## Project Structure
- `mobile_price_prediction.ipynb` – Model development and analysis
- `Mobilephone_data_final.csv` – Smartphone dataset
- `app.py` – Gradio prediction application
- `saved_model/` – Trained model and preprocessing files
- `requirements.txt` – Python dependencies

## Installation

Clone the repository:

```bash
git clone YOUR_REPOSITORY_URL
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
python app.py
```
